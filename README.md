# Project 22: AutoCare HTML Template

A modern, responsive, multi-purpose HTML template designed for service-based businesses, auto repair shops, and mechanics.

## Structure
- `pages/`: Contains all HTML files.
- `assets/css/`: Main styles, dark mode, and RTL overrides.
- `assets/js/`: Main scripts and plugin configurations.
- `assets/images/`: Images and graphical assets.
- `documentation/`: Additional setup guides.

## Setup
Simply open `pages/index.html` in a web browser to view the template.

## Integrations (Placeholders)
- Contact form is ready for integration with Formspree.
- Newsletter subscribe is styled.
- Booking system integration points included.
